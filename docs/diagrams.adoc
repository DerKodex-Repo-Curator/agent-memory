This page catalogs all diagrams in the neo4j-agent-memory documentation, tracking ASCII art diagrams and their Excalidraw conversions.

== Diagram Workflow

The documentation uses a structured workflow for managing diagrams:

1. **ASCII Art Source**: Diagrams are initially created as ASCII art in documentation files
2. **Excalidraw Conversion**: ASCII diagrams are converted to Excalidraw JSON format
3. **PNG Export**: Excalidraw files are exported to PNG for display in docs
4. **Image Reference**: Documentation files include image references to the PNG

=== Tools

* `make docs-diagrams-status` - Show all diagrams and their Excalidraw status
* `make docs-diagrams-missing` - Show diagrams without Excalidraw files
* `make docs-diagrams-add-refs` - Add image references to documentation files
* `make docs-diagrams-generate` - Generate prompts for creating missing Excalidraw files

=== File Locations

* **Excalidraw JSON**: `docs/assets/images/diagrams/excalidraw/*.excalidraw`
* **PNG Exports**: `docs/assets/images/diagrams/*.png`
* **Management Script**: `scripts/manage_diagrams.py`

== Diagram Style Guidelines

When creating new diagrams, follow these guidelines:

=== Neo4j Color Palette

Use consistent colors for memory types:

[cols="2,2,2"]
|===
|Memory Type |Background |Stroke

|Short-Term Memory
|`#b2f2bb` (light green)
|`#2f9e44` (green)

|Long-Term Memory
|`#ffec99` (light yellow)
|`#f08c00` (orange)

|Reasoning Memory
|`#d0bfff` (light purple)
|`#9c36b5` (purple)

|Neo4j/Storage
|`#a5d8ff` (light blue)
|`#1971c2` (blue)
|===

=== Diagram Types

* **Architecture**: Use rectangles with hierarchy (top-level -> components -> storage)
* **Flowchart**: Use vertical flow with colored boxes and arrows
* **Cypher/Graph**: Use ellipses for nodes, labeled arrows for relationships
* **Sequence**: Use vertical lifelines with horizontal message arrows
* **Table**: Use rectangles arranged in grid with headers
